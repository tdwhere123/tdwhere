# AGENTS.md

## Cursor Cloud specific instructions

This is a client-side single-page app: React 19 + TypeScript + Vite 7, styled with Tailwind CSS v3. The live app lives in `src/atelier` (mounted from `src/main.tsx`). It is a bilingual (zh/en) personal portfolio site. There is no backend, database, or API — everything runs in the browser.

### Services

Single frontend service only.

- Dev server: `npm run dev` (Vite, serves on port `3000`, configured in `vite.config.ts`).
- Build: `npm run build` (runs `tsc -b` then `vite build`).
- Lint: `npm run lint` (ESLint flat config; currently passes).
- Unit tests: `npm run test` (Vitest).
- Preview built output: `npm run preview`.

### Notes

- Puppeteer smoke: `node scripts/e2e-smoke.mjs [baseUrl]` (default `http://localhost:4173/tdwhere/`). Needs Chrome (`CHROME_PATH` or a common system binary). Not wired into CI.
- No environment variables or secrets are required to run the app.
- Asset delivery: see `scripts/ASSET-DELIVERY.md`. External font CSS is non-blocking. Film thumbnails (320w) and shelf previews (640w) are generated automatically by the Sharp/Vite plugin in `scripts/film-assets.ts`; original viewer/painter images are unchanged. Authored grounds live separately in `src/atelier/grounds.ts`, so the shell does not load the gallery catalog.
- Painted fields: `Art` (`src/atelier/components/Primitives.tsx`) defers generation/graphics until visible and uncovered, and paints each field procedurally (`src/atelier/paint/painter.ts`) or, given a `frame`, repaints one of the author's film photographs stroke by stroke, and renders it live through the WebGL2 engine (`paint/engine.ts`, `paint/shaders.ts`, per-art presets in `paint/presets.ts`; frames use the `film` preset). Without WebGL2 or with reduced motion (or with `still`) it shows the same painting as a still image. A prepainted layer given `flow` (the image's horizon) has living water: chop running toward the viewer below the horizon and the brightest strokes winking. Every painting smears with fast scrolling (`uSmear`). Scenes talk to a mounted painting only through `paint/bus.ts` channels (`home`, `memory`, …) in client coordinates (`reveal` and `depth` are held signals like `light`); never import the engine directly. The pointer's wet wash is `components/WetTrail.tsx` (mouse only, no custom cursor shape).
- Home: the painting is `shell/HomeFrame.tsx`, mounted by the shell, not the page: the sea at Zhujiajian (`heroFrame` in `src/atelier/grounds.ts`, frame 43 of the 2023-11-05 Zhoushan roll with the left edge cropped; `HORIZON` is its sea line), prepainted by `scripts/bake-home.mjs` with `paintHome()`/`seaColor()` in `paint/painter.ts` (cobalt and ultramarine water, viridian beside it, cream foam, ochre in the lit swell and the rock, a rose-cream sky; no black) as `src/assets/ground/home-painted.webp` (1600 px), `home-painted-2560.webp` (chosen by `homePainting()` for dense screens) and `home-relief.webp`. Its light is the visitor's own hour (`src/atelier/daylight.ts`, sent through the bus as `light`); there are no seasons, weather or captions for it. `pages/Home.tsx` is the person first (the name written on in 志莽行书 with `tdwhere` in Homemade Apple, then "我是阿黄，一个独立探索者。" and one plain line about the work), then a scroll dive (`.a-dive`, a sticky stage driven by a GSAP ScrollTrigger timeline) that sends `depth` to the painting while the first three entries of `src/atelier/projects.ts` come up one at a time, then Film/Notes/About. Home's `<main>` lets the pointer through (`pointer-events: none`, links excepted), so a hand over the water stirs the paint. Leaving `/` by any link keeps HomeFrame up over the page that has already arrived and sends `part`: the tide runs up the painting and takes the paint away under a lace of foam (`uPart` in `paint/shaders.ts`; `TIDE_MS` in `paint/presets.ts`, waited for by `PART_MS` in `shell/Shell.tsx`). The tide waits for committed route content; a quick return home cancels it.
- Opening (`shell/Opening.tsx`, `shell/opening.ts`): the first visit of a session that lands on `/` (motion allowed) is a loading screen that is the painting being made: real progress (the painting and its relief, the fonts, the Projects/Blog/Film/About chunks, the engine), never faster than `MIN_MS`, sets the held `reveal` signal, and the engine lays the strokes on the site's paper (sky and headland first, the sea far to near, the light last). A mono counter and line sit on top; click or Escape finishes at once; a 9 s cap keeps a stalled request from holding the visitor. When it is done the name is written on and the nav fades in. The old overture (the island, aerator, coots, weather clock and its models) is gone.
- Motion (`src/atelier/motion.ts`): Lenis inertial scrolling for the whole site (nested scrollers keep native scroll; `data-lenis-prevent` opts out) driving GSAP's ScrollTrigger; one curve and three lengths (`EASE`, `T`, mirrored as `--a-ease`, `--a-t-*`). After a page's lazy content has arrived the shell calls `enter(main)`: headings marked `data-rise` come up line by line out of a mask (SplitText), blocks marked `data-fade` settle in, each once, on first view. Only mark static content (filtered lists re-render nodes the pass never sees). Text links roll their words with `.a-flip` (not `.a-roll`, which belongs to the film strip). Reduced motion turns all of this off.
- Type: three hands, one per level, and nothing else. Titles (`h1`, `--a-brush`): 志莽行书 for Chinese with Homemade Apple for Latin; everything read (headings, body, `--a-serif`/`--a-text`): LXGW WenKai, set in weight and size; notes, dates and labels (`--a-mono`): DM Mono. No English eyebrow captions, numbering, two-line couplets or hand-lettered asides; copy is plain.
- Notes (`/blog`, `/blog/:slug`): set on char (`data-page='notes'`), each note a cream sheet with burnt edges (`--a-burnt` in `styles/pages/notes.css`, one SVG used as a nine-slice `border-image`; keep its middle flat or it tiles into a lattice). Previous/next between notes go through `components/BurnLink.tsx`: `shell/BurnLayer.tsx` (WebGL2) scorches the page from where it was touched, chars it behind a glowing edge, changes route under the ash and lets the ash break up to show the next note. Without WebGL2 or with reduced motion the page simply turns. The reading progress is a smouldering line.
- Film (`/film`, `/film/:roll/:frame`): photos live in `src/assets/film/<roll>/` and are picked up by `import.meta.glob` in `src/atelier/film.ts` — no code change to add a roll. Name a roll folder `YYYY-MM[-DD]-name` to date it (newest first; undated last); frames sort by file name, numerically. An optional `roll.json` gives `title`, `place`, `stock`, `camera`, `note`, and per frame (file name without extension) `alt` and `focus`. The collection shows each roll as a 35mm canister colored after its `stock` (printed in the sea's blues on the shelf, its own colors when pointed at or open) (`components/Canister.tsx`; no maker's marks, speed dropped) with the date or title on masking tape; choosing one (`?roll=`) pulls out its strip. The viewer is full screen (nav and footer hidden) with the roll's strip below and an as-shot / repainted switch.
- do-it (`pages/DoIt.tsx`): the two-terminal scenes (`components/duelScenes.ts`, played by `components/Duel.tsx`) are illustrations, each naming its source (a real session on this site, or a do-it behavior-eval scenario) on the page. The skill map (`components/SkillMap.tsx`) and per-host install screens (`components/Hosts.tsx`, drawn after the author's screenshots in `.do-it/Example/`; the host marks in `src/assets/doit/` are cut from them) follow the do-it repository (0.18.1: skills' SKILL.md, `agents/*.toml`, `docs/install.md`). Keep names, quoted hook text and commands in step with it rather than inventing new ones.
- SENTINEL (`/sentinel`, `pages/Sentinel.tsx`): the painted machine (`components/PaintedMachine.tsx`) powers on into a full-screen desk (`sentinel/Desk.tsx`, portaled to `body`) that plays one night of review by choices: the same machine (`machine/MachineStage.tsx`) sits fixed on the desk with the machine's lines live on its glass, the story on paper beside it, documents as slips. Keep the desk cheap to draw: its machine is `fixed` (no pointer lean), the page's machine is `paused` while the desk covers it, and the wet wash stays off the desk (`data-dry`). Lines with a `clip` can be copied into the ledger (`sentinel/Ledger.tsx`, a paged book: rule twelve, a self-sorting timeline, the copied sentences marked trusted or doubtful); the record may cite only trusted clips. The story is pure data in `src/atelier/sentinel/` (`script.ts` state and line helpers, `clips.ts` every copyable sentence with its source and the titles it backs, plus the timeline, `story.ts` scenes, `ending.ts` the five-act ending), checked by `story.test.ts`, which plays thousands of random nights and expects every ending to be reachable. Every line is a zh/en pair; the prose follows the plain style of the field note `day-1-myth`. The archived title is kept in `localStorage` (`tdwhere:sentinel`) and quoted by the next night. Switching off keeps the night in progress. The old easter-egg cards and the PRD are gone; the Elsewhere page holds only Vegetarian-card now.
- Palette colors in `tailwind.config.js` are mapped through `--*-rgb` channel variables (declared in `src/index.css`) so Tailwind `/opacity` modifiers compose — always add the channel variable when adding a color, never reference a bare `var(--color)` in the Tailwind palette.
- Controls: prefer text-style controls (underlined tabs, mono labels, plain lists) over capsule buttons and chips; the author finds pills unattractive, so use `rounded-full` only with a specific reason. Corner-radius system: cards and panels `rounded-xl`–`rounded-[28px]`, small controls `rounded-md`; `--radius` in `src/index.css` is the base scale. Keep sharp corners only where they are an intentional motif (stamps, gallery plate brackets).
- Icons come from `lucide-react` only; no emoji in UI surfaces.
