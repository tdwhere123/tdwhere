# AGENTS.md

## Cursor Cloud specific instructions

This is a client-side single-page app: React 19 + TypeScript + Vite 7, styled with Tailwind CSS v3. The live app lives in `src/atelier` (mounted from `src/main.tsx`). It is a bilingual (zh/en) personal portfolio site. There is no backend, database, or API — everything runs in the browser.

### Services

Single frontend service only.

- Dev server: `npm run dev` (Vite, serves on port `3000`, configured in `vite.config.ts`).
- Build: `npm run build` (runs `tsc -b` then `vite build`).
- Lint: `npm run lint` (ESLint flat config; currently passes).
- Unit tests: `npm run test` (Vitest).
- Preview built output: `npm run preview`.

### Notes

- Puppeteer smoke: `node scripts/e2e-smoke.mjs [baseUrl]` (default `http://localhost:4173/tdwhere/`). Needs Chrome (`CHROME_PATH` or a common system binary). Not wired into CI.
- No environment variables or secrets are required to run the app.
- Painted fields: `Art` (`src/atelier/components/Primitives.tsx`) paints each field procedurally (`src/atelier/paint/painter.ts`) or, given a `frame`, repaints one of the author's film photographs stroke by stroke, and renders it live through the WebGL2 engine (`paint/engine.ts`, `paint/shaders.ts`, per-art presets in `paint/presets.ts`; frames use the `film` preset). Without WebGL2 or with reduced motion (or with `still`) it shows the same painting as a still image. Scenes talk to a mounted painting only through `paint/bus.ts` channels (`home`, `memory`, …) in client coordinates; never import the engine directly. The pointer's wet wash is `components/WetTrail.tsx` (mouse only, no custom cursor shape).
- Home: the painting is `shell/HomeFrame.tsx` (the hero film frame repainted, `heroFrame` in `src/atelier/film.ts`), mounted by the shell, not the page; `pages/Home.tsx` is only the name, four ways in, and the weather line that replays the overture (`shell/overtureCue.ts`). Leaving `/` by any link keeps HomeFrame up over the page that has already arrived and sends a `part` signal: a palette knife crosses the painting and parts the paint to show the new page (`uPart` in `paint/shaders.ts`; timing in `paint/engine.ts`, matched by `PART_MS` in `shell/Shell.tsx`). No film-strip styling outside the film pages.
- Overture (`shell/Overture.tsx`, `paint/overture.ts`): the first visit of a session that lands on `/` shows a 2.5D block of water on paper under the visitor's own sky. `src/atelier/weather.ts` reads the local clock: month → season, hour → light, date → the day's weather (rain, sun, wind, mist, snow; the same all day). Touching the water rings it; the line beneath enters, sinking into the water onto the home painting. Escape skips. It is off on reduced motion and without WebGL2.
- Film (`/film`, `/film/:roll/:frame`): photos live in `src/assets/film/<roll>/` and are picked up by `import.meta.glob` in `src/atelier/film.ts` — no code change to add a roll. Name a roll folder `YYYY-MM[-DD]-name` to date it (newest first; undated last); frames sort by file name, numerically. An optional `roll.json` gives `title`, `place`, `stock`, `camera`, `note`, and per frame (file name without extension) `alt` and `focus`. The collection shows each roll as a 35mm canister colored after its `stock` (`components/Canister.tsx`; no maker's marks, speed dropped) with the date or title on masking tape; choosing one (`?roll=`) pulls out its strip. The viewer is full screen (nav and footer hidden) with the roll's strip below and an as-shot / repainted switch.
- do-it (`pages/DoIt.tsx`): the two-terminal scenes (`components/duelScenes.ts`, played by `components/Duel.tsx`) are illustrations, each naming its source (a real session on this site, or a do-it behavior-eval scenario) on the page. The skill map (`components/SkillMap.tsx`) and per-host install screens (`components/Hosts.tsx`, drawn after the author's screenshots in `.do-it/Example/`; the host marks in `src/assets/doit/` are cut from them) follow the do-it repository (0.18.1: skills' SKILL.md, `agents/*.toml`, `docs/install.md`). Keep names, quoted hook text and commands in step with it rather than inventing new ones.
- SENTINEL (`/sentinel`, `pages/Sentinel.tsx`): the painted machine (`components/PaintedMachine.tsx`) powers on into a full-screen desk (`sentinel/Desk.tsx`, portaled to `body`) that plays one night of review by choices: the machine's lines in screen panels, the story on paper, documents as slips. Lines with a `clip` can be copied into the ledger (`sentinel/Ledger.tsx`, a paged book: rule twelve, a self-sorting timeline, the copied sentences marked trusted or doubtful); the record may cite only trusted clips. The story is pure data in `src/atelier/sentinel/` (`script.ts` state and line helpers, `clips.ts` every copyable sentence with its source and the titles it backs, plus the timeline, `story.ts` scenes, `ending.ts` the five-act ending), checked by `story.test.ts`, which plays thousands of random nights and expects every ending to be reachable. Every line is a zh/en pair; the prose follows the plain style of the field note `day-1-myth`. The archived title is kept in `localStorage` (`tdwhere:sentinel`) and quoted by the next night. Switching off keeps the night in progress. The old easter-egg cards and the PRD are gone; the Elsewhere page holds only Vegetarian-card now.
- Palette colors in `tailwind.config.js` are mapped through `--*-rgb` channel variables (declared in `src/index.css`) so Tailwind `/opacity` modifiers compose — always add the channel variable when adding a color, never reference a bare `var(--color)` in the Tailwind palette.
- Controls: prefer text-style controls (underlined tabs, mono labels, plain lists) over capsule buttons and chips; the author finds pills unattractive, so use `rounded-full` only with a specific reason. Corner-radius system: cards and panels `rounded-xl`–`rounded-[28px]`, small controls `rounded-md`; `--radius` in `src/index.css` is the base scale. Keep sharp corners only where they are an intentional motif (stamps, gallery plate brackets).
- Icons come from `lucide-react` only; no emoji in UI surfaces.
