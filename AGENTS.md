# AGENTS.md

## Cursor Cloud specific instructions

This is a client-side single-page app: React 19 + TypeScript + Vite 7, styled with Tailwind CSS v3. The live app lives in `src/atelier` (mounted from `src/main.tsx`). It is a bilingual (zh/en) personal portfolio site. There is no backend, database, or API — everything runs in the browser.

### Services

Single frontend service only.

- Dev server: `npm run dev` (Vite, serves on port `3000`, configured in `vite.config.ts`).
- Build: `npm run build` (runs `tsc -b` then `vite build`).
- Lint: `npm run lint` (ESLint flat config; currently passes).
- Unit tests: `npm run test` (Vitest).
- Preview built output: `npm run preview`.

### Notes

- Puppeteer smoke: `node scripts/e2e-smoke.mjs [baseUrl]` (default `http://localhost:4173/tdwhere/`). Needs Chrome (`CHROME_PATH` or a common system binary). Not wired into CI.
- No environment variables or secrets are required to run the app.
- Asset delivery: see `scripts/ASSET-DELIVERY.md`. External font CSS is non-blocking. Film thumbnails (320w) and shelf previews (640w) are generated automatically by the Sharp/Vite plugin in `scripts/film-assets.ts`; original viewer/painter images are unchanged. Authored grounds live separately in `src/atelier/grounds.ts`, so the shell does not load the gallery catalog.
- Painted fields: `Art` (`src/atelier/components/Primitives.tsx`) defers generation/graphics until visible and uncovered, and paints each field procedurally (`src/atelier/paint/painter.ts`) or, given a `frame`, repaints one of the author's film photographs stroke by stroke, and renders it live through the WebGL2 engine (`paint/engine.ts`, `paint/shaders.ts`, per-art presets in `paint/presets.ts`; frames use the `film` preset). Without WebGL2 or with reduced motion (or with `still`) it shows the same painting as a still image. Scenes talk to a mounted painting only through `paint/bus.ts` channels (`home`, `memory`, …) in client coordinates; never import the engine directly. The pointer's wet wash is `components/WetTrail.tsx` (mouse only, no custom cursor shape).
- Home: the painting is `shell/HomeFrame.tsx` (the hero film frame repainted, `heroFrame` in `src/atelier/grounds.ts`; prepainted as `src/assets/ground/home-painted.webp` by `scripts/bake-home.mjs`), mounted by the shell, not the page; `pages/Home.tsx` is only the name, four ways in, and the weather line that replays the overture (`shell/overtureCue.ts`). Leaving `/` by any link keeps HomeFrame up over the page that has already arrived and sends a `part` signal: a palette knife crosses the painting and parts the paint to show the new page (`uPart` in `paint/shaders.ts`; timing in `paint/engine.ts`, matched by `PART_MS` in `shell/Shell.tsx`). Home and the overture use the same prepared painting and `paint/light.ts` sky-to-pigment light; HomeFrame sends light through the paint bus. The prepared still remains until the first live draw. The knife waits for committed route content; a quick return home cancels it. No film-strip styling outside the film pages.
- Overture (`shell/Overture.tsx`, `paint/overture.ts`): the first visit of a session that lands on `/` shows a 2.5D block of water on paper with the yellow paddlewheel aerator from the hero photograph turning in it (`paint/island/aerator.ts`), the sun's glitter crossing the far water through the day; entering sinks into the glitter beside it. Clicking the aerator stops or starts it. Coots (`paint/island/birds.ts` behavior, checked by `birds.test.ts`; `coot.ts` model) paddle about with V-wakes, glance and paddle gently away when greeted directly (or leave their perch), and climb onto the pontoons while it stands still. After dusk the scene is lit, not just darkened: the mast lamp, lights along the far shore with their trails on the water, and the moon's glitter. The island keeps its own time (`src/atelier/weather.ts`): a session clock starts at the visitor's hour and season, then one island day passes in 20 minutes (`DAY_MS`) and each day brings the next season, a year in 80. Each day turns through spells of weather (rain, sun, wind, mist, snow; `SPELL_HOURS`), each easing into the next; `islandSky` in `paint/island/state.ts` blends light and weather for the renderer every frame. The home page's weather line reads the same clock. Canvas taps target a coot, the machine, or open water; dragging rotates the view without also tapping. Text controls provide keyboard/touch equivalents and report machine state. Touching the water rings it; the line beneath enters, sinking into the water onto the home painting. Escape skips. It is off on reduced motion and without WebGL2.
- Film (`/film`, `/film/:roll/:frame`): photos live in `src/assets/film/<roll>/` and are picked up by `import.meta.glob` in `src/atelier/film.ts` — no code change to add a roll. Name a roll folder `YYYY-MM[-DD]-name` to date it (newest first; undated last); frames sort by file name, numerically. An optional `roll.json` gives `title`, `place`, `stock`, `camera`, `note`, and per frame (file name without extension) `alt` and `focus`. The collection shows each roll as a 35mm canister colored after its `stock` (`components/Canister.tsx`; no maker's marks, speed dropped) with the date or title on masking tape; choosing one (`?roll=`) pulls out its strip. The viewer is full screen (nav and footer hidden) with the roll's strip below and an as-shot / repainted switch.
- do-it (`pages/DoIt.tsx`): the two-terminal scenes (`components/duelScenes.ts`, played by `components/Duel.tsx`) are illustrations, each naming its source (a real session on this site, or a do-it behavior-eval scenario) on the page. The skill map (`components/SkillMap.tsx`) and per-host install screens (`components/Hosts.tsx`, drawn after the author's screenshots in `.do-it/Example/`; the host marks in `src/assets/doit/` are cut from them) follow the do-it repository (0.18.1: skills' SKILL.md, `agents/*.toml`, `docs/install.md`). Keep names, quoted hook text and commands in step with it rather than inventing new ones.
- SENTINEL (`/sentinel`, `pages/Sentinel.tsx`): the painted machine (`components/PaintedMachine.tsx`) powers on into a full-screen desk (`sentinel/Desk.tsx`, portaled to `body`) that plays one night of review by choices: the same machine (`machine/MachineStage.tsx`) sits fixed on the desk with the machine's lines live on its glass, the story on paper beside it, documents as slips. Keep the desk cheap to draw: its machine is `fixed` (no pointer lean), the page's machine is `paused` while the desk covers it, and the wet wash stays off the desk (`data-dry`). Lines with a `clip` can be copied into the ledger (`sentinel/Ledger.tsx`, a paged book: rule twelve, a self-sorting timeline, the copied sentences marked trusted or doubtful); the record may cite only trusted clips. The story is pure data in `src/atelier/sentinel/` (`script.ts` state and line helpers, `clips.ts` every copyable sentence with its source and the titles it backs, plus the timeline, `story.ts` scenes, `ending.ts` the five-act ending), checked by `story.test.ts`, which plays thousands of random nights and expects every ending to be reachable. Every line is a zh/en pair; the prose follows the plain style of the field note `day-1-myth`. The archived title is kept in `localStorage` (`tdwhere:sentinel`) and quoted by the next night. Switching off keeps the night in progress. The old easter-egg cards and the PRD are gone; the Elsewhere page holds only Vegetarian-card now.
- Palette colors in `tailwind.config.js` are mapped through `--*-rgb` channel variables (declared in `src/index.css`) so Tailwind `/opacity` modifiers compose — always add the channel variable when adding a color, never reference a bare `var(--color)` in the Tailwind palette.
- Controls: prefer text-style controls (underlined tabs, mono labels, plain lists) over capsule buttons and chips; the author finds pills unattractive, so use `rounded-full` only with a specific reason. Corner-radius system: cards and panels `rounded-xl`–`rounded-[28px]`, small controls `rounded-md`; `--radius` in `src/index.css` is the base scale. Keep sharp corners only where they are an intentional motif (stamps, gallery plate brackets).
- Icons come from `lucide-react` only; no emoji in UI surfaces.
