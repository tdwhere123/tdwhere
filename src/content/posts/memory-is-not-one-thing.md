## 记忆的内外

免责条款：我理解的不一定是事情的全貌，但我以我认知的方式去讲述这一段内容。希望各位佬友如果有耐心阅读，可以一块讨论研究~

这期我在标题里去掉了 Agent，原因在于到了这一部分，“记忆”的内涵已经有了更深的延展。我将它暂时区分为“模型内记忆”与“模型外记忆”。严格来说，这样的分类并不完全科学，因为两者在真实系统中经常相互嵌套，但为了方便讨论，它可以提供一个比较直观的理解框架。

我们先暂许一个定义：凡是以模型原生的参数、激活、潜状态或可训练模块存在，并直接参与后续计算的内容，都可以暂时称为“模型侧记忆”。与之相对，前面几篇讨论的RAG、事实账本、知识图谱、Memory File等，则统一划入模型外记忆。

为了方便理解，我们可以区分出五种典型的记忆形态。它们并非严格互斥，而是从不同的存储与更新机制描述过去如何进入当前计算：

| 载体 | 典型形式 | 记忆如何影响模型 |
|---|---|---|
| 参数 | 基础权重、LoRA、Adapter | 改变模型长期行为倾向 |
| 上下文激活 | Token、KV Cache | 被注意力直接读取 |
| 循环状态 | RNN 状态、SSM 状态、Memory Tokens | 作为下一步计算的初始状态 |
| 潜在记忆 | Soft Tokens、Memory Slots | 以模型原生向量注入 |
| 快权重 | Test-time weights、神经记忆模块 | 推理期间通过更新参数改变函数 |

从用户侧的感知来看，两者也有很大区别。模型内记忆往往以用户无法直接理解的形式存在，很难精确查看、修改或删除；模型外记忆则更像“查字典”，虽然显得笨重，却天然具有较强的可治理性。

整个模型内记忆的发展，其实可以围绕四组长期存在的矛盾来理解：

**压缩与保真、稳定与可塑、模型原生与人类治理、当前任务与未知未来。**

这四组矛盾并不只存在于模型内部，在模型外记忆中同样存在。归根结底，它们都在追问三个问题：**记忆应该以什么形式储存，应该怎样被更新，以及过去究竟怎样影响现在的行为。**

### 从“记住模式”到“维护状态”

在研究的时候，发现原来神经网络中的记忆并不是从大语言模型开始的，很早以前，研究者就在思考：一个神经网络能否在看到部分线索时，自动恢复过去学到的完整模式。

1982 年的 Hopfield Network 是这一思想的经典代表（可以去搜一下，联想记忆）。它没有像数据库一样把每一条记忆放在一个确定地址，而是把模式编码进整个网络的连接结构。当我们提供一个残缺输入 ($x_0$) 时，网络状态不断演化：

$$
x_0 \rightarrow x_1  \rightarrow x_2 \rightarrow \cdots \rightarrow x^*
$$

最终收敛到一个稳定状态 ($x^*$)。这个稳定状态可以理解为某段被“想起来”的记忆。这就是内容寻址记忆：我们不是告诉系统“去地址 1527 读取数据”，而是给出一个部分线索，让系统自己恢复与它最匹配的模式。这里的记忆主要储存在连接权重和能量地形里。也就是说，召回不一定就绑死了位置索引这一种路径，也可以通过形成稳定状态的地形来确定召回的内容。

2020 年，《Hopfield Networks is All You Need》进一步指出现代 Hopfield Network 与 Transformer Attention 之间存在很深的数学联系。从这个角度看，今天的注意力机制本身就具有某种联想记忆的性质。但 Hopfield Network 主要解决的是模式恢复，而不是长时间持续运行的问题。当神经网络开始处理连续序列时，另一个问题变得更加重要：**我是否真的需要保存所有过去，还是只要维护一个“截至现在”的状态？**

这就是 RNN 的核心思路：

$$
h_t=f_\theta(h_{t-1},x_t)
$$

其中 ($x_t$) 是当前输入，($h_{t-1}$) 是此前全部历史压缩形成的状态，模型把两者结合，形成新的 ($h_t$)。

这是一种非常不同的记忆观。模型不再保存“过去发生过哪些事件”，而是让过去不断改变当前状态。1997 年提出的 LSTM 又进一步加入门控机制，使模型能够学习哪些信息应该写入、哪些应该保留、哪些应该遗忘。

如果我们稍微抽象一点，这条路线可以写成：

$$
M_{t+1} =U(M_t,x_t)
$$

其中 $M_t$ 不再是一条历史记录，而是模型在时刻 $t$ 对过去的压缩结果。

这类方法的优势是明显的：无论经历一千步还是一百万步，状态大小都可以保持固定。但它的问题同样明显——如果无限多的历史最终都被压缩进一个有限状态，那么信息损失几乎不可避免。它很适合回答“我们现在进行到哪里”，却很难保证回答“第八千步具体发生了什么”。

这就是我们发现的第一组矛盾：**压缩与保真。**

### 从“压成一个状态”到“直接访问过去”

2014 年前后的 Memory Networks、Neural Turing Machine，以及之后的 Differentiable Neural Computer，开始尝试另外一种方案：既然一个隐藏状态装不下全部历史，那就给神经网络增加一块可以主动读写的 Memory。

其基本结构可以写成：

$$
M_{t+1} =\operatorname{Write}( M_t , x_t )
$$

$$
r_t = \operatorname{Read}( M_t , q_t )
$$

$$
y_t = F_\theta (x_t,r_t)
$$

这里的 ($M_t$) 是一组可以被寻址的记忆槽位。模型不仅学习解决任务，还学习应该把信息写到哪里、什么时候读取、如何更新。Neural Turing Machine 试图构造一种“神经网络控制器 + 可微内存”，Differentiable Neural Computer 则进一步加入内存分配、顺序链接等机制，使模型能够学习更复杂的数据结构操作。

这条路线与今天的 Agent Memory 已经有些相似：计算和存储开始被明确区分。

但真正改变主流路径的是 2017 年的 Transformer。Transformer 做了一件看似相反的事情：与其把历史提前压缩进固定状态，为什么不尽可能保留过去，让当前 token 直接去访问它？

Self-Attention 的核心形式是：

$$
\operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
$$

其中当前查询 (Q) 可以与上下文中的所有 (K) 比较，再读取相应的 (V)。从记忆角度看，Transformer 的上下文窗口和 KV Cache 都可以理解为一种高保真的临时记忆。

RNN 的思想是：

$$
\text{History}\rightarrow h_t
$$

Transformer 的思想则更接近：

$$
\text{History}\rightarrow {K_1,V_1,\ldots,K_t,V_t} \rightarrow\text{按需访问}
$$

它避免了过早压缩，因此在精确引用、长距离关联等任务上取得了巨大优势。但问题也随之转移：历史越长，KV Cache 越大，Attention 的计算和存储压力也越高。

后来的 Transformer-XL、Compressive Transformer、Memorizing Transformer，本质上都在这个矛盾上寻找不同位置。Transformer-XL 尝试跨片段复用隐藏状态；Compressive Transformer 把更久远的激活进一步压缩；Memorizing Transformer 则干脆把过去产生的内部 Key-Value 表示存下来，通过 kNN 在需要时重新取回。后者尤其值得注意，因为它与 RAG 非常相似，只不过 RAG 搜索的是文档，而 Memorizing Transformer 搜索的是模型过去自己的内部激活。换言之，“查字典”的思路并没有消失，它甚至可以直接发生在模型内部。

与此同时，Recurrent Memory Transformer 又重新引入了一种循环思路。它在每个上下文片段之间传递少量 Memory Tokens：

$$
M_{t+1}=U_\theta(M_t,X_t)
$$

这些 Memory Tokens 不对应具体文字，却会吸收上一段上下文的信息，并成为下一段计算的一部分。Transformer 因此重新获得了一种类似 RNN 的连续状态，只不过这个状态变成了模型原生的潜空间表示。

模型记忆的发展到这里形成了一种反复摆动：**究竟是应该尽量保留过去，需要时再检索；还是应该不断压缩过去，只维持一个当前状态？**

前者保真但昂贵，后者便宜但容易遗忘。到目前为止，这个问题仍没有真正消失。

### 当记忆不再需要被写成人类语言

我们把视角投到另一条相关的线索——潜空间记忆。

要理解它，需要先回到模型最底层的输入方式。自然语言经过 tokenizer 后会变成 token ID，再通过 Embedding Table 转成向量：

$$
x_i=E[\operatorname{token}_i]
$$

所以语言模型实际上从来没有“看到文字”，它看到的是：

$$
X=[x_1,x_2,\ldots,x_n]
$$

既然如此，我们能不能跳过“真实 token”这一步，直接给模型一组人为训练出来的向量？这就是 Soft Token 的基本思想。

2021 年的 Prefix-Tuning 首先证明，我们完全可以冻结大语言模型本身，只优化一组连续向量：

$$
Z=[z_1,z_2,\ldots,z_k]
$$

然后把它们与正常 token embedding 一起交给模型：

$$
X'=[Z;X]
$$

这些 ($z_i$) 不对应任何词，却能够稳定地改变模型输出。而所谓“冻结模型”其实并不意味着训练完全停止。模型的基础参数 ($\theta$) 不更新，但梯度仍然可以穿过模型，训练这些新的参数或模块：

$$
\hat y=F_\theta(C_\phi(H),q)
$$

其中 ($F_\theta$) 是冻结的大语言模型，($C_\phi$) 是压缩器。训练时我们固定：

$$
\theta=\text{constant}
$$

只更新：

$$
\phi\leftarrow\phi-\eta\nabla_\phi L
$$

于是压缩器会逐渐学会：应该生成怎样的向量，才能让这个固定语言模型产生正确答案。

这里岔开，我们也可以从中看出 Soft Token 与标准 retrieval Embedding 的根本区别。检索 Embedding 的训练目标通常是：

$$
\operatorname{sim}(E(q),E(d^+))> \operatorname{sim}(E(q),E(d^-))
$$

它只需要把相关内容放得更近，因此主要承担“地址”的作用。Soft Token 则直接进入语言模型计算，其目标是改变：

$$
P(y\mid Z,q)
$$

因此它更像某个特定模型能够理解的内部编码。

2023 年的 Gist Tokens、AutoCompressor 和 ICAE 又进一步提出：如果 Soft Token 可以承载信息，那么是否能够把一大段真实历史压缩成少量这样的向量？我们可以把一个压缩器抽象成：

$$
C_\phi: \mathbb R^{n\times d} \rightarrow \mathbb R^{k\times d}, \qquad k\ll n
$$

例如把一千个历史 token 压成十六个 Memory Slots：

$$
Z=C_\phi(H)
$$

Gist Tokens 通过修改 Attention Mask，强迫长指令的信息只能经过少量特殊 Token 才能到达后续任务；如果这些 Token 没有成功携带必要信息，模型就会答错，梯度会迫使它们逐渐形成有效的信息瓶颈。

AutoCompressor 和 ICAE 则更明确地训练“历史 $\rightarrow$ 潜在记忆”的映射。压缩后的结果不再是“用户喜欢简洁回答”这样的摘要文字，而可能只是十几个模型内部向量。下一次使用时也无需重新 tokenizer 和理解文字，而可以直接把这些向量接回模型。

这条路线对于图片、音频、视频尤其重要，因为自然语言本身是一种有损接口。一张图片经过 Caption 以后，大量空间、颜色、动作和细节信息会消失，而视觉编码器产生的潜在向量则有机会保留一些难以语言化的特征。因此潜空间记忆真正值得关注的地方，并不是“比文本省几个 token”，而是它可能允许智能体直接保存一种非语言化的经验表示。

但这立即引出了第三组矛盾：**模型原生与人类治理。**

Soft Memory 可以很高效，但通常与具体模型的隐藏空间绑定。模型 A 产生的潜在记忆，不一定能被模型 B 使用；模型升级以后，旧 Memory Slots 也可能失效。更重要的是，人类很难回答“这个向量到底记住了什么”“怎样只删除其中一条事实”。

相比之下，一条普通文本记录虽然效率低，却可以跨模型阅读、修改、迁移和审计。

### 从“保存数据”到“改变一个函数”

时间来到最近两年，最值得关注的变化，发生在 Fast Weights 与 Test-Time Learning 这条线上。

传统模型一般有两种东西：长期稳定的参数 ($\theta$)，以及每次推理不断变化的激活 ($h_t$)。Fast Weights 很早便提出过一个介于两者之间的概念：某些参数可以在运行过程中快速变化，用来保存当前任务中的临时经验。

2024 年的 TTT layers 将这一思想重新带入序列建模。它提出，隐藏状态不一定非得是一个向量：

$$
h_t\in\mathbb R^d
$$

它也可以本身就是一个小型模型：

$$
W_t
$$

当新信息 ($x_t$) 到来时，这个小型模型通过一次自监督学习发生更新：

$$
W_{t+1}=W_t-\eta\nabla_W\ell(W_t;x_t)
$$

于是过去不再只是被“存储”在某个地方，而是直接改变了一个函数。未来查询 (q) 到来时，模型不是检索某条历史，而是经过这个已经被历史塑造过的函数：

$$
r_t=W_t(q)
$$

Titans 延续了这一思路。它把 Attention 看作精确但容量有限的短期记忆，同时增加一个能够在测试阶段持续更新的 Neural Memory，用来承担更长期的记忆。ATLAS 等后续工作又继续研究如何增加这种 Test-Time Memory 的容量与更新能力。

如果说 RAG 的思想是：

$$
\text{Past} \rightarrow \text{Storage} \rightarrow \text{Retrieval} \rightarrow \text{Current Action}
$$

那么 Test-Time Memory 更接近：

$$
\text{Past} \rightarrow \Delta W \rightarrow \text{Current Model} \rightarrow \text{Current Action}
$$

这是一种相当不同的记忆观：**记忆不一定是一个等待读取的对象，也可以是过去经历造成的模型变化。**

从这个角度看，世界模型其实是同一方向更进一步的延展。世界模型不强调“记住具体发生过什么”，而强调从大量经验中学习世界的变化规律：

$$
p(s_{t+1}\mid s_t,a_t)
$$

也就是在状态 ($s_t$) 下采取动作 ($a_t$)，下一状态 ($s_{t+1}$) 可能是什么。Dreamer 一类工作甚至让智能体在学习到的潜在世界中“想象”不同动作的未来结果，再据此规划行为。这意味着过去经验最终可能有三种完全不同的去向：一部分成为可以回溯的事件记忆，一部分被压缩成“世界现在是什么样”的信念状态，还有一部分最终内化为“这个世界通常怎样变化”的预测模型。

### 记忆最终不是一种东西

我们现在回头再看模型侧记忆的发展，我们会发现它并不是一条从旧方法到新方法的单线升级，而是在不断重新分配“过去”应该以什么形式存在。

参数记忆 ($\theta$) 保存的是长期知识与能力；KV Cache 和上下文激活保存的是短期高保真历史；循环状态 ($M_t$) 保存的是对过去的持续压缩；Soft Tokens 与 Memory Slots 保存的是模型原生的潜在经验；Fast Weights ($W_t$) 则让过去直接改变一个运行中的函数。

因此，一个成熟的长期智能体很可能不会只有一种 Memory，而会同时具有多个时间尺度：

$$
\theta \quad \text{稳定知识与能力}
$$

$$
KV_t \quad \text{精确短期上下文}
$$

$$
Z_t \quad \text{潜在工作记忆}
$$

$$
W_t \quad \text{快速学习形成的神经状态}
$$

以及模型外的：

$$
D \quad \text{事实、事件与原始证据账本}
$$

它们分别位于不同位置，承担不同责任。

这也让“模型内还是模型外”这个问题显得没有那么绝对。模型外记忆擅长回答“过去究竟发生了什么”，因为它可以保留原始证据、时间、来源和版本；模型内记忆更擅长回答“过去如何改变我现在”，因为经验可以改变模型的状态、偏好、预测与行为方式。（注：近期看到很多Agent memory系统在做所谓的改变模型状态，所谓的过去影响现在，免责声明是我没有看过它们如何实现的，只是在原理上我不太理解，它们的改变是什么意义上的改变）

模型侧记忆的发展脉络，我们可以理解为一部**过去的信息怎样进入当前计算的思想史**：从最初把记忆写进网络连接，到不断维护隐藏状态；从保留完整上下文，到把历史压成模型自己的潜在语言；再到今天开始尝试让过去直接改变一个正在运行的学习过程。而开头提到的四组矛盾，也始终没有消失。压缩越强，越可能丢失未来需要的细节；状态越稳定，越难快速吸收新的经验；表示越接近模型原生空间，就越难被人类理解和治理；而任何根据当前任务训练出的记忆压缩机制，都无法提前知道未来究竟会需要什么。

也许因此，汇归我们第三期提出的问题，可能真正完整的长期记忆系统的合理演化结果是：**让外部记忆负责保存可以证明的过去，让模型内部记忆负责承载过去留下的影响。**
